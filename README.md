# Fábrica de escova de dentes sustentável: estudo de viabilidade

Página única (HTML, CSS e JavaScript) com análise de viabilidade, painel de custos, modelo 3D da fábrica,
mapa 3D das regiões, modelo 3D do encaixe da escova e painel de edição.

## Como ver
Abra `index.html` no navegador. Precisa de internet para carregar o Three.js (cdnjs) e as fontes do Google.

## Como editar
- Botão "Editar", no canto da tela, abre as abas de edição (imóveis, motivos, máquinas e preços, regiões, riscos, cronograma, textos, parceria e dados).
- As edições feitas no navegador ficam salvas só nesse navegador. Para levá-las ao repositório, use a aba "Dados" (exportar) e peça a atualização do arquivo.

## Publicar no GitHub Pages
1. Suba `index.html` na raiz do repositório.
2. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
3. O endereço sai como `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
